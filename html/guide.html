工作流程

构建模拟浏览器会话
curl_cffi 依次尝试 chrome133a / chrome131 / safari18_0 / firefox133 指纹，自动检测系统代理（Windows 注册表 / 环境变量），选定第一个能通过 Cloudflare 验证的指纹。
翻页抓取列表（第 1~4 页）
从 /category/wpcz/1/ 到 /4/，新内容在第一页最前面；解析全部帖子链接与标题，带 2 秒请求间隔。
关键词筛选 + 去重检查
标题含「内射 / 巨乳 / 大奶 / 无套 / 乘骑」任一即命中；命中的帖子先查 SQLite（downloaded.db），已下载的直接跳过。
提取 m3u8 地址
从帖子页源码（含内联 JS 转义）提取 HLS 地址；找不到时自动检查 iframe 播放页（最多 3 个）。
下载视频（AES-128 自动解密）
有 ffmpeg → 直接合并为 mp4；没有 → 纯 Python 逐段下载、AES-128-CBC 解密、拼接为 .ts。文件小于 0.05 MB 判为失败并清理。
写入数据库 + 提前停止翻页
成功后把帖子 URL / 标题 / 文件路径 / 时间写入 downloaded.db；某页命中帖子全部已下载过时提前停止（新内容总在最前页）。

使用方法

pip install -r requirements.txt        # curl_cffi + beautifulsoup4 + pycryptodome

python crawler.py                      # 正式执行一轮
python crawler.py --dry-run            # 只列出命中帖子，不下载
python crawler.py --max-pages 4        # 指定爬取页数（默认 4）
python crawler.py --loop               # 常驻模式：每 24 小时自动执行
python crawler.py --loop --interval-hours 12

每天定时运行（Windows 任务计划程序，推荐）

管理员 PowerShell 执行一次即可（每天 09:00 自动跑，路径按实际修改）：

schtasks /Create /TN "51cg1爬虫" /TR "cmd /c cd /d C:\path\to\crawler-51cg && python crawler.py >> run.log 2>&1" /SC DAILY /ST 09:00

删除任务：schtasks /Delete /TN "51cg1爬虫" /F。也可以直接用 --loop 常驻模式（需保持终端开启）。

媒体库：本地播放服务

python server.py 启动后自动打开 http://127.0.0.1:8787：

• 视频按下载时间倒序排列，点击即播，支持拖动进度条（HTTP Range）
• 播放过的视频标题前自动加 ✅，记录持久化在 viewed_posts 表
• .mp4 原生播放；.ts 用内置 mpegts.js 软解（已本地化 vendor/mpegts.min.js，无需联网）
• 与爬虫共用 downloaded.db，爬虫下载完点「刷新列表」即可看到

注意事项

⚠ 本机需能访问该站点（当前环境自动走系统代理 127.0.0.1:7897，可直达）。换网络环境后若所有指纹均被拦，请更新 IMPERSONATE_CANDIDATES 或更换代理出口。
